# pairwise-workflow-guard

审批流支持多级审批后，状态机绕过就能让单据跳级通过：客户端直接传 `approved`，跳过中间节点；上一节点的审批 token 能重放到下一节点；审批人只校验登录，不校验当前节点角色；并行分支只完成一个就整体通过；驳回后还能继续 approve；状态迁移没有白名单；旧版本单据能重新提交；委托审批没有范围限制；批量审批跳过单条校验；审批意见能改写历史记录。security/workflow_guard.py 是核心，tests/test_workflow_guard.py 15个红。要修的是：状态服务端推进；节点 token 一次性；节点角色校验；并行汇合校验；驳回终态；迁移白名单；版本号校验；委托范围限制；批量逐条校验；历史只追加。

## 运行

```bash
python -m pytest tests -q
```
